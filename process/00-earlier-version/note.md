# First attempt (September 3, 2026)

The first portfolio page I made for this module, uploaded straight to GitHub
through the web interface. It is kept here unedited, exactly as it was
published, because it is the first point of comparison in the process:

1. **This page** (Sept 3): résumé content styled as a web page.
2. **The baseline** (`../01-baseline/`, Sept 22): what one sentence and my
   résumé produce with no direction at all.
3. **The refined site** (the home page of this repository, Sept 23): built
   from a written brief with an audience, a target role and four case files.

It is also the reason the refined version leads with case files instead of
résumé sections: this page and my résumé say the same things in the same
order, and a recruiter already has the résumé.

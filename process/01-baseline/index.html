Portfolio Tracker App

A portfolio analytics web app I built in Python with Streamlit and deployed live. It measures risk-adjusted performance across a multi-asset portfolio and solves for optimal weights.

  • Sharpe and Sortino ratios
  • Rolling volatility and drawdowns
  • Correlation and covariance matrices
  • Global minimum-variance and tangency portfolios
  • The Markowitz efficient frontier
  • Risk contribution for each asset
  • A custom builder with interactive weight sliders
  • Sensitivity to the estimation window

Built with Python, Streamlit, Git and GitHub, VS Code, and AI coding tools (ChatGPT, Claude, Gemini).
